## 四、全局约定（摘自主文档，各模块文档不再重复）

- 技术栈：Java 17 + Spring Boot 3.5（无虚拟线程，CompletableFuture + 线程池）+ MyBatis-Plus 3.5.16 + Nacos/jasypt + Dify Workflow（主文档 §1.2）。
- 落位：`nqboard-sniper`（api/biz 双子模块，端口 6008，网关路由 `/sniper/**`，包 `com.mx.nqboard.sniper`，主文档 §1.1）。
- **拒因字符串是跨系统契约**：23 个 `RejectReason.code()` 与 Python 版逐字节一致（主文档 D5），CI 契约测试锁死。
- **fail-closed**：LLM 调用失败/超时/JSON 非法一律拒票或降 watch，绝不消费默认/占位输出（主文档 D4）。
- **单位口径**：行情/快照表原样入库 + `source` 列标注；事件/资金类表入库即换算成 Python client 层对外单位（元、股、小数比例），权威矩阵见主文档 §4.3.0。
- 查询接口一律 MyBatis-Plus `LambdaQueryWrapper`（参数绑定，禁手拼 SQL），返回体一律 `R<T>`。
- **接口路径三层约定（对齐 device 等现有模块）**：本文各模块文档"后端接口"表中的 `/sniper/**` 路径均为**前端/网关路径**；平台网关 `NqBoardRequestGlobalFilter` 做全局 StripPrefix=1，因此 Controller 的 `@RequestMapping` **不带 `/sniper` 前缀**（对齐 device 的 `@RequestMapping("/category")` 写法）。路由需在 Nacos `nqboard-gateway-dev.yml` 增加 `- id: nqboard-sniper-biz / uri: lb://nqboard-sniper-biz / Path=/sniper/**`（限流配置对齐 device 路由样式）。
- **分页规范**：多行列表分页一律按平台**延迟关联**范式实现（先分页查 id、再按 id 批量查详情、按页序内存回填；过滤条件抽取 `buildQueryWrapper` 单一来源；无用户排序时 `orderByDesc(id)` 兜底），**禁止直接 `service.page` 全列分页**（开发手册"分页查询规范"）。
- **Controller 标配注解**：类上 `@Tag` + `@SecurityRequirement(name = HttpHeaders.AUTHORIZATION)`，方法上 `@Operation`；写操作（手动扫描/刷新/回填/跟踪/复盘）加 `@SysLog` 与 `@HasPermission("sniper_资源_动作")`。
- **分层纪律**：业务表 CRUD 一律走平台标准 `XxxService extends IService<XxxEntity>` + `ServiceImpl` + `Mapper extends BaseMapper`；`algorithm/ data/ llm/ pipeline/` 是本模块**有意的扩展包**（纯算法域零 Spring 依赖可单测、数据接入唯一 IO 边界、编排门面），不属于平台模板包，不得在其中夹带 CRUD。
- 对拍通过标准：主文档 §12（数据级/指标级/漏斗级/gate 级/报告级/LLM 级/影子运行）；判定口径见 §12 头注——数据级按存储精度取整后相等、计算级容差 1e-9（相对）、拒因字符串字节级。
