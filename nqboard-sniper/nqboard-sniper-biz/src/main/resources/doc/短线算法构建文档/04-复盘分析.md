# 04 复盘分析（菜单组实施规划）

> 规格来源：[`../nqboard-migration-plan.md`](../nqboard-migration-plan.md)（主文档）§9.5（review 统计）、§10（每周 ReviewService）、§12（验收）。菜单归属：主文档 §1.4 复盘分析组（6310）。
> 定位：**纯聚合读模块**——不建新表、不拉外部数据，聚合 03 台账数据产出绩效统计、四组分桶与胜率红线告警。对应主文档分期 **M6**（业务上必须 03 先跑出平仓数据）。

## 0. 模块范围与菜单

| 菜单(ID) | 页面 | 操作按钮 |
|---|---|---|
| 复盘看板(6310) | 绩效汇总 + 四组分桶 + 红线告警条 | 生成复盘 `sniper_review_run`(6311)；导出 `sniper_review_export`(6312) |

依赖字典：`sniper_position_status`、`sniper_close_reason`、`sniper_scan_action`。

## 1. 数据库设计

**无新表。** 数据来源：

- `sniper_ledger_position` / `sniper_ledger_mark`（03 模块写入，本模块只读聚合）；
- `sniper_scan_report.market_ret_5d`（市场环境分桶的原始值来源，仓位行已冗余同名列）。

聚合结果有两种产出：① 接口实时聚合（看板查询）；② `ReviewService` 周任务产物导出 `review_<date>.md`（主文档 §10：每周五 16:00，现状为 `track_signals.py --review` 每周手动）。如后续需要留存历史复盘快照，再增 `sniper_review_snapshot` 表（**本期不做**，避免过度设计）。

## 2. 统计口径（主文档 §9.5，照搬 `review.py` 语义）

**样本口径（最重要的纪律）**：只统计真实成交（`_closed_trades`）——**never_filled 与 gap_abort 都不计入**胜率/收益统计（gap_abort 是市场否定信号、never_filled 未发生交易），但两者在"异常仓位"区独立展示计数。

| 指标 | 定义 |
|---|---|
| 胜率 | pnl_pct > 0 的真实平仓数 ÷ 真实平仓总数 |
| 平均净收益 | mean(pnl_pct)（含费用后的净值） |
| 平均超额 | mean(excess_ret)（vs 沪深300 同区间） |
| 平均持有天数 | mean(close_date − entry_date) |
| profit_factor | 总盈利 ÷ 总亏损（绝对值，pnl 口径） |

**四组分桶**（互相独立，不做交叉表）：

| 维度 | 分桶 | 说明 |
|---|---|---|
| 置信度 | 5 桶：0-30 / 30-50 / 50-70 / 70-85 / 85+ | 取 `sniper_ledger_position.confidence` |
| 理由标签 | 按 reasons 数组展开计数（一票多标签各计一次） | 偏多因子标签 |
| 快筛分 | 4 桶：<40 / 40-50 / 50-60 / 60+ | 取 screen_score |
| 市场环境 | market_up / market_down | **由 market_ret_5d ≥ 0 派生，不是存储字段** |

## 3. 胜率红线告警（Java 新增能力，不改变统计口径）

- 规则：**连续两周（两个周复盘周期）胜率 < 40% → 输出"暂停实盘"告警**（出处：[`../每日操作指南.md`](../每日操作指南.md) §六，现状是人工纪律，主文档 §9 将其固化为 ReviewService 的自动告警输出）。
- 输入：每周期（周）的真实平仓胜率序列；实现上按 cohort_date 的 ISO 周聚合胜率，取最近两个完整周判断。
- 展示：看板页顶红线条（正常不显示/绿色通过，触发时红色横幅 + 触发周期与数值）；同时 `review_<date>.md` 头部固定输出该结论。

## 4. 接口数据与数据库字段映射（聚合口径）

| 聚合维度 | 源列 | 聚合方式 |
|---|---|---|
| 真实平仓集合 | `status='closed' AND close_reason IN ('stop_loss','horizon')` | `_closed_trades` 等价过滤 |
| 指标四件套 | `pnl` / `pnl_pct` / `excess_ret` / `close_date`、`entry_date` | SQL 聚合或内存计算（数据量小，内存计算保证分桶灵活） |
| 置信度桶 | `confidence` | 固定 5 桶边界 |
| 理由标签桶 | `reasons`（JSON 数组） | 展开 flatten 后 group |
| 快筛分桶 | `screen_score` | 固定 4 桶边界 |
| 市场环境桶 | `market_ret_5d` | `>=0 → market_up else market_down` |
| 异常计数 | `close_reason='gap_abort'` / `'never_filled'` | 独立 count，不入绩效指标 |
| 红线 | 上述胜率按 ISO 周 group | 最近两周均 <0.40 → 告警 |

## 5. 入库/写入规则

- 本模块**不改台账数据**；唯一写入是 `review_<date>.md` 导出文件（与 Python `reports/` 目录同构，落盘位置与 scan 产物一致管理）。
- 周任务（Quartz 每周五 16:00）与手动按钮调用**同一个** `ReviewService`，无独立状态存储。

## 6. 后端接口

落位：`pipeline/ReviewService` + `controller/ReviewController`。

> 下表路径为**前端/网关路径**（`/sniper/**`）；Controller 的 `@RequestMapping` 不带 `/sniper` 前缀（平台网关全局 StripPrefix=1，对齐 device `/category` 写法），路由在 Nacos `nqboard-gateway-dev.yml` 增加（README 全局约定）。写操作（`/run`）加 `@SysLog` + `@HasPermission`，类上 `@Tag`/`@SecurityRequirement`、方法上 `@Operation`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/sniper/review/summary` | 汇总指标；参数 from/to（默认全部历史） |
| GET | `/sniper/review/buckets` | 分桶；参数 dim=confidence\|reason\|screen\|market、from/to |
| GET | `/sniper/review/redline` | 红线状态（最近两周胜率、是否触发） |
| GET | `/sniper/review/abnormal` | gap_abort / never_filled 计数与明细入口 |
| POST | `/sniper/review/run` | 生成当期复盘（周任务同一 Service）；权限 `sniper_review_run` |
| GET | `/sniper/review/export` | 导出 `review_<date>.md`；权限 `sniper_review_export` |

## 7. 页面定义（复盘看板 6310）

1. **页顶红线告警条**：绿色"胜率达标"或红色"连续两周胜率 <40%，暂停实盘（附两周期数值）"。
2. **汇总卡片区**：胜率、平均净收益、平均超额、平均持有天数、profit_factor 五张卡；右上角时间范围选择器。
3. **四组分桶区**：置信度 5 桶 / 理由标签 / 快筛分 4 桶 / 市场环境——各为一组"桶 × 胜率 × 平均超额 × 样本数"的表+柱状图；样本数 <5 的桶灰显（统计不显著提示）。
4. **异常仓位区**：gap_abort / never_filled 计数卡（不计入绩效的说明文案固定展示），点击跳 03 仓位台账预筛。
5. 操作：生成复盘（刷新当期聚合）、导出 md。

## 8. 对拍与验收

| 项 | 方法 | 通过标准 |
|---|---|---|
| 口径一致 | 同一份台账数据跑 Python `review.py` 与 Java ReviewService | 指标与分桶逐项一致；never_filled/gap_abort 均不计入 |
| 红线 | 构造连续两周 <40% fixture | 告警触发且 `review_<date>.md` 头部输出结论 |
| 影子运行 | 与 Python 双跑 | 周复盘输出一致 |

## 9. 模块边界

- **上游**：03 台账（只读聚合）；市场环境派生规则在本模块（03 只存原始值）。
- **下游**：无（终端展示模块）；`review_<date>.md` 导出供人工存档，与 Python 版产物同构。
- **不做**：策略参数自动调优（分桶只做事实呈现）；跨模块写任何表。
