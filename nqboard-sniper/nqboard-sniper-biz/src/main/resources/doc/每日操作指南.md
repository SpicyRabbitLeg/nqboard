## 一、每日运行时间

| 时段 | 建议 | 说明 |
|---|---|---|
| 交易日 15:30 之后 | ✅ **推荐** | 收盘数据齐了，扫描结果即"明日操作清单" |
| 交易日盘中 | ⚠️ 可用 `--intraday` | 用实时价当当前价，但当日数据未定型，信号仅供参考 |
| 周末 / 节假日 | ✅ 可复盘 | 自动回退到最近交易日数据（`as_of` 为上一交易日） |

> 提示：每日缓存默认开启（`CN_DAILY_CACHE_ENABLED=true`），同一天重复扫描不会重复拉行情，第二次跑会快很多。

## 二、标准运行命令

```bash
poetry run python scripts/scan_buy_signals.py \
  --universe hs300_csi500 \   
  --model glm-5.3 \  
  --max-deep 8 \             
  --max-screen 50 \           
  --trial-cash 100000 \      
  --verbose \                
  --output reports/scan_all.json
```

### 常用参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--universe` | 必填 | `all` 全市场 / `hs300` / `csi500` / `hs300_csi500` |
| `--tickers 600028.SH,...` | - | 指定股票直接深度分析（跳过漏斗） |
| `--model` | 无 | LLM 名称；不传则全程纯规则模式，零 API 消耗 |
| `--max-deep` | 8 | Stage 2 深度分析数量（每只消耗大量数据请求+LLM调用） |
| `--min-confidence` | 70 | 门槛：最低置信度 |
| `--min-bullish` | 3 | 门槛：最少偏多分析师数 |
| `--intraday` | 关 | 盘中模式，用实时价 |
| `--show-reasoning` | 关 | 打印分析师详细推理 |

## 三、输出文件解读

运行结束后 `reports/` 下生成两个文件（按数据日期命名，如 `scan_2026-08-28.*`）：

- **`scan_<日期>.json`** -- 结构化完整报告（程序/回测用）
- **`scan_<日期>.md`** -- 人类可读版，**先看这个**

### Markdown 报告结构

```
# 报告头：数据日期
## 概览        -> 漏斗统计、市场5日涨幅、预算消耗 ← 快速判断今天值不值得做
## 买入信号汇总 -> 表格：股票/置信度/得分/建议股数/占用资金/核心逻辑
## 各股详情    -> 每只的偏多因子 + 7 个分析师信号表（🟢偏多 🔴偏空 ⚪中性）
## 被门槛拒绝   -> 被刷掉的股票和原因（复盘用）
```

### 关键指标怎么看

| 指标 | 含义 | 操作参考 |
|---|---|---|
| **置信度** (confidence) | 综合决策的把握度 0-100 | ≥80 高把握；70-80 常规；贴着 70 谨慎 |
| **加权得分** (weighted_score) | 多因子加权，越高越强 | ⚠️ 挖掘显示负 IC，**已不作门槛**，仅作报告参考 |
| **偏多因子** (reasons) | 有几个分析师看多 | 因子越多共振越可靠；只有 1-2 个要小心 |
| **趋势预测** (trend_predictor) | 未来 5 日方向 | 方向不是 up 的慎重，警惕追高 |
| **risk_flags** | 风险标记 | 非空（如解禁临近）必须人工核查 |

### 门槛规则（全部通过才发 entry_ok）

1. 置信度 ≥ 70（`CN_SCAN_MIN_CONFIDENCE`）
2. 偏多分析师 ≥ 3（`CN_SCAN_MIN_BULLISH_AGENTS`）
3. ~~加权得分 ≥ 0.35~~ **已停用**（`CN_SCAN_MIN_WEIGHTED_SCORE=0`）——2026-09-15 全市场挖掘（4.77 万样本）显示该分数与 T+5 收益**负相关**（IC -0.058），分数越高越差，继续用它选股等价于反向筛选。如需恢复把 `.env` 中该值改回 0.35
4. 技术面置信度 ≥ 50（`CN_GATE_MIN_TECH_CONFIDENCE`）
5. 趋势预测非 up 时，ADX ≥ 25（`CN_GATE_FLAT_TREND_MIN_ADX`，排除"无趋势却靠总分过关"）
6. 单行业最多 1 只（`CN_SCAN_MAX_PER_INDUSTRY`，同行业信号按置信度留最强，其余降级为 `industry_cap` 拒绝）
7. **每日全局最多 1 只**（`CN_SCAN_MAX_SIGNALS_PER_DAY`，全部门槛通过后按置信度取最强 1 只，其余降级为 `daily_cap` 拒绝；0=不限）
8. **LLM 硬失败拒票**（`CN_LLM_FAIL_HARD=true` 默认开）——任一分析师的 LLM 调用重试耗尽即标记该票 `llm_error`，gate 直接拒绝（拒因 `llm_unavailable:*`），绝不基于不完整证据发信号；空仓决策合成失败时降级规则结果且所有 entry_ok 降为 watch。设为 false 恢复旧的静默降级行为

另有多重否决项：**过热/过度延伸否决**（RSI6 ≥ 90、5日动量 > 4.5% 或 < -1%、趋势强度 > 0.46 直接剔除，快筛与门槛双层生效，`CN_SCAN_MAX_RSI6` / `CN_SCAN_MAX_MOMENTUM_5D` / `CN_SCAN_MIN_MOMENTUM_5D` / `CN_SCAN_MAX_TREND_STRENGTH`；阈值依据 2026-09-15 全市场挖掘报告 `reports/research/mining_2026-09-15.md`——动量 >4.5%、<-1% 与趋势强度 >0.46 是最差 T+5 组，训练/验证两段方向一致）、趋势非 up 且技术弱、基本面情绪空、市场硬门槛等，被拒股票会列在"被门槛拒绝"表中。

## 四、每日操作流程（SOP）

### 1️⃣ 盘后扫描（15:30 后）

```bash
poetry run python scripts/scan_buy_signals.py \
  --universe hs300_csi500 --model glm-5.3 \
  --max-deep 8 --max-screen 50 --trial-cash 100000 \
  --verbose --output reports/scan_all.json
```

耗时约 10-15 分钟（首次），缓存命中后更快。

### 2️⃣ 信号跟踪（盘后，扫描完接着跑）

把每次扫描的信号自动记入模拟台账：T+1 开盘模拟成交（含费用；低开超过 2% 视为信号被市场否定，放弃入场）→ 每日记录涨跌与相对沪深300超额 → 破止损线（默认 -3%，`CN_TRACK_STOP_PCT`）即平仓 / T+5 收盘自动平仓 → 可随时出复盘统计。

```bash
poetry run python scripts/track_signals.py \
  --output reports/track.json --verbose
```

- 台账：`data/signal_tracking/ledger.json`（幂等，重复跑不会重复入账）
- 台账视图：`reports/ledger.md`（每次运行自动刷新，打开即看全部待入场/持仓中/已平仓与累计盈亏）
- 日报：`reports/track_<日期>.json` / `.md`（每只票持仓第几天、累计涨跌、超额、最大浮盈/回撤）
- 复盘：随时加 `--review` 输出胜率统计（`reports/review_<日期>.md`），按置信度/偏多理由/快筛得分/市场环境分桶，用于调门槛参数

### 3️⃣ 阅读报告（5 分钟）

打开 `reports/scan_<日期>.md`：

- **无信号** -> 今日空仓观望，结束 ✅
- **有信号** -> 进入复核

### 4️⃣ 人工复核（10 分钟，必做！）

对每只信号股票检查：

- [ ] **news 核查**：有无报告未覆盖的突发利空（公告/诉讼/减持）
- [ ] **risk_flags**：是否为空；非空则查解禁/ST/停牌事项
- [ ] **位置判断**：技术面 `overbought_oversold:bearish` 高置信 + RSI 高位 = 短期超买，考虑等回踩
- [ ] **分析师分歧**：🟢🔴 混杂（如情绪偏空但技术偏多）-> 降低仓位或放弃

### 5️⃣ 次日执行（开盘后）

- **建仓**：按报告中"建议股数"分 1-2 笔买入；盘中大幅高开（>+3%）不追，等回落
- **仓位控制**：单票不超过总资金 20%，同时持仓 ≤ 5 只
- **持仓周期**：默认 5 个交易日（`CN_SHORT_HORIZON`）

### 6️⃣ 持仓管理（每日）

- 每日盘后重跑扫描，已持仓股票用 `--tickers` 单独复查：

```bash
poetry run python scripts/scan_buy_signals.py \
  --tickers 600028.SH,600918.SH --model glm-5.3 \
  --trial-cash 100000 --verbose --output reports/holdings.json
```

- **止盈**：达到预期收益（参考 trend_predictor 的预期收益）或信号转弱即出
- **止损**：跌破 **-3%**（与台账自动止损线 `CN_TRACK_STOP_PCT` 统一）或决策转为 avoid 无条件出局
- **到期**：持有满 5 个交易日仍未达预期，减半仓或清仓

### 7️⃣ 每周复盘

- 跑一次复盘统计，看信号的真实胜率与拖累来源：

```bash
poetry run python scripts/track_signals.py --review --output reports/track.json
```

- 结合复盘报告分桶结果调参：某置信度桶平均收益为负 → 上调 `CN_SCAN_MIN_CONFIDENCE`；某理由标签（如"情绪偏多"）持续拖累 → 降低对应 Agent 权重或门槛
- 检查"被门槛拒绝"表中是否错杀（confidence 高但被单项否决的股票）
- 预算经常耗尽（`requests_used 300/300`）可调大 `CN_SCAN_MAX_AKSHARE_REQUESTS` 或换 Tushare 积分更高的账号

## 五、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `401 Authentication Fails ... api key invalid` | LLM Key 无效/过期 | 检查 `.env` 对应厂商的 Key；规则模式（不传 `--model`）不受影响 |
| `Error in LLM call after 3 attempts` 后仍跑完 | LLM 重试耗尽，硬失败模式生效（默认） | 涉及 LLM 的分析师把相关股票标记 `llm_error`，gate 会拒绝这些票；报告"被门槛拒绝"表中可见拒因 `llm_unavailable:*`。修好 Key 后重跑即可恢复 |
| 扫描很慢、大量重试 | AkShare/EM 被限流 | 等待或调大 `AKSHARE_REQUEST_DELAY_SECONDS`；确认 Tushare Token 有效（Tushare 快得多） |
| `Stage1 skipped N tickers (budget)` | AkShare 主源模式下请求预算耗尽 | 属正常保护机制；Tushare 主源模式不受此预算限制（自动快筛全宇宙）；AkShare 模式需扩大覆盖面则调大 `CN_SCAN_MAX_AKSHARE_REQUESTS` |
| 报告里出现 `market_gate_blocked` | 沪深300 近5日涨幅 < `CN_SCAN_MARKET_MIN_RET`（当前 0，即五日下跌就禁开仓） | 市场环境差，系统禁止开仓：扫描直接输出空报告、跳过漏斗与 Agent 分析（不耗 LLM 调用）。这是 2026-09 台账复盘后开启的规则（下跌批次胜率仅 28.6%），不要手动绕过 |
| 数据日期不是今天 | 周末/节假日或盘中未用 `--intraday` | 正常，自动回退最近交易日 |
| 报告 `signals` 为空数组 | 无股票通过门槛 | 正常现象，宁缺毋滥；也可放宽 `--min-confidence` 试验 |

## 六、风险纪律（务必遵守）

1. **信号是参考不是指令**：所有 entry_ok 都要过人工复核，模型不知道突发新闻
2. **单票 ≤ 20% 仓位**，总持仓 ≤ 5 只
3. **止损铁律 -3%**（`CN_TRACK_STOP_PCT`，人工执行与台账自动止损同一条线），不抗单、不补仓
4. **市场门槛触发时空仓**，不要手动绕过
5. **超买股票不追**：`overbought_oversold:bearish` 高置信时等回踩
6. 每周复盘命中率，连续两周 <40% 命中则暂停实盘，回测调参
